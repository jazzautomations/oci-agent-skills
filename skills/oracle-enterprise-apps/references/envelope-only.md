# Service envelope versus application

For most Oracle SaaS/PaaS questions, separate OCI instance lifecycle, networking, capacity and work requests from application data, configuration and transactions. The service API and application API can have different endpoints, identities, privileges and licenses.
Do not invent an OCI CLI command for a business object. Fusion environment inventory does not read invoices or employees; Analytics instance inventory does not query analyses; Integration instance state does not inspect or run an integration flow.
Digital Assistant is an explicit exception: the installed 3.91 research inventory measured 95 of 119 leaves under oda management, including skills, channels, assistants and auth providers. Those reach the content plane and require content-specific authorization. The count is version-specific, not a service guarantee.
WebLogic Management is another operational nuance: it can perform domain lifecycle and patch actions, not just list an envelope. Keep this skill's execution to projected reads; route patch proposals to oci-migration-patching. Service availability differs by realm and entitlement; absent resources are not evidence that a SaaS product does not exist.
