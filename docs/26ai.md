# 26ai retrieval kit

[Runnable preparation and five-minute presentation](../demos/26ai-rag/README.md) combine
in-database ONNX embeddings, 384-dimensional vectors, HNSW and Oracle hybrid search.
Select AI and SQLcl MCP are optional paths with their own grants/quota prerequisites.

All provisioning and SQL mutation commands default to dry-run. A dedicated private lifecycle
record prevents teardown from accepting unrelated database IDs. No existing ADB was touched.

[Preflight evidence](evidence/26ai-preflight.md) preserves the earlier read-only check.
The [September 11 integration](live-validation-2026-09-11.md) records real paid
provisioning, schema/model/corpus setup, valid HNSW and hybrid indexes, SQLcl MCP reads,
bounded privilege-denial checks and retrieval measurements. Free-tier provisioning,
large-corpus performance and held-out relevance remain unverified.

The [follow-up lab](second-validation-2026-09-11.md) validated the final 100-word
loader on 15 documents/632 chunks, repeat loading without duplicates, valid indexes
and default document fusion: 45/45 expected-source hits across 15 development
questions repeated three times. The old vector baseline scored 39/45; fusion is
slower and was selected using these development results. Object-specific unified
audit captured an actual SQLcl read and denied write without agent privilege
expansion. This does not certify SQLcl's own log table, retention or all operations.
See the dated reports for teardown and billing status.
